# Project 00 — Linux + Git + GitHub

## Project Overview

This project introduces the basic tools used in modern software
development, including the Linux terminal, Git, GitHub, and SSH.

## Objectives

- Learn how to navigate directories using Linux commands.
- Create, copy, rename, and remove files.
- Understand Git version control.
- Create and manage a GitHub repository.
- Document a project using Markdown.
- Learn how SSH keys authenticate securely with GitHub.

## Tools Used

- Linux Terminal
- Bash
- Git
- GitHub
- SSH
- Markdown

## Project Structure

- ex00: Terminal navigation and directory creation.
- ex01: File manipulation using a shell script.
- ex02: Creating and pushing a GitHub repository.
- ex03: Project documentation and SSH authentication.

## Why Git Makes Development Easier

Git helps developers keep track of changes made to their code.
Each commit records a snapshot of the project, making it easier
to understand its history and return to an earlier version when
necessary.

Git also supports teamwork. Developers can work on separate
branches, review changes, and combine their work into a shared
project. This helps organize collaboration and makes changes
easier to track.
